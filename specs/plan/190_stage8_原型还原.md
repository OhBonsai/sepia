## 附录 A · 实施中自行判掉的设计空白（190 §0：判了记这里，不停下等人）

### A-1 · ⌘B 冲突（190 P1 点名要先裁）

**裁决：侧边栏让位，改 `⌘\`。⌘B 归加粗。**

理由是频次与性质：加粗是**写作动作**，一天按几十次，且 D-26 把它连同
⌘I/⌘E 一起定成了一组肌肉记忆，拆开一个就等于整组都要想一下；
侧边栏是**视图开关**，一天按几次。`⌘\` 不是凭空挑的——Obsidian 的左侧栏就是它，
用户的肌肉记忆不必从零建。

同一轮里 `⌘/` 也从 CM6 的 `toggleComment` 手里收了回来（Stage 7 已做）。
**新占一个 `Mod-x` 之前先看 `defaultKeymap` 里有没有它**——这条写进了
`editor/base.ts` 的 `APP_OWNED_KEYS` 注释。

### A-2 · `readDoc` 从 base.ts 迁到 bytes.ts

F2 的格式命令要读全文，而它是 `base.ts` 的下游；`readDoc` 留在 base 里就成了
`base → format → base` 的环，`check:deps` 的 no-circular 当场红。
迁到 `bytes.ts` 是**归位**而不是妥协：那个文件守的就是"不许全文规范化换行"这一条，
`readDoc` 存在的唯一理由也是它。base 里保留一行 re-export，既有 import 路径不破。
