## 1.2 范围

**⌘/ 命令面板**
- [ ] 浮层列出全部注册命令（title 经 copy、显示键位）；模糊搜索；回车执行；Esc 关
- [ ] 无参命令直接执行；带参命令（rename/move）唤起后走最小 prompt 行（面板内一行输入）
- [ ] 顺手核账：registry 里每条命令的 title/copy 键齐全（缺文案在此暴露）

**⌘⇧I 信息浮层**
- [ ] 内容如 §1.1 表；数据全部来自既有通道（save-pipeline 状态、git 留痕、threads 派生、books 身份），**桥零增长优先**，确需新查询单列申报
- [ ] commit 失败留痕从此可见（架构 §4.2"⌘⇧I 留痕"的兑现）

**保存微反馈 + 失败终态链**
- [ ] 成功微反馈（600ms 淡点）；失败链：重试 3（1s/3s/9s 退避）→ 持久警示 + 横条
- [ ] 拦截关闭：脏且写盘不可用时关窗/⌘Q 出确认（明示未落盘字数）；其余一切退出仍无对话框
- [ ] IME 组合期间不重试打扰（沿用 5a 挂起机制）

**happy-path 终验**
- [ ] 机器面：全量 check + 全部 smoke 一轮全绿（这就是机器清单）
- [ ] 人工面：分镜逐条走查表制成 evidence/180/checklist.md，人勾选；发现缺陷按"不通过→修→复验"记
- [ ] 原型 W1–W12 逐场景对照一遍（缺席 W12、还白 W10、线程 W11 等此前分散验过的在真实流程里连起来验）

**明确不做（刹车）**
新功能一律不做｜设置 UI｜主题切换 UI｜导出｜重试次数/退避可配置（写死）｜
⌘⇧I 里放操作按钮｜命令面板做成启动器（只列已注册命令）｜任何债表里的项（除 §1.1 二的唯二例外）

## 1.4/1.5 harness（破坏预写，元规则全套适用）
| # | 检查 | 破坏方式（瞄唯一那道保护） |
|---|---|---|
| 1 | 单测 · 重试退避（假计时器）：3 次后停、成功即止 | 无限重试 / 失败一次就放弃 → 必红 |
| 2 | 单测 · 拦截判定：脏+写盘不可用才拦，其余不拦 | **把"其余不拦"破坏掉 → 必红**（误拦比漏拦更违反 ⌘Q 无对话框原则） |
| 3 | smoke · 命令面板：⌘/ 出面板→搜到 files.trash→回车执行 | 面板不出/执行断 → 必红 |
| 4 | smoke · ⌘⇧I 内容断言（含 commit 失败留痕一条） | 留痕不显示 → 必红 |
| 5 | smoke · 微反馈：保存成功点现→600ms 隐（像素级，160 手法） | 常亮/不现 → 必红 |
| 6 | smoke · 终态链：chmod 555 → 打字 → 3 次重试痕迹 → 关窗出拦截 → 恢复权限 → 重试成功拦截消 | 链上任一环断 → 必红 |
| 7 | smoke · happy-path 机器串联：一条 spec 从冷启动→写→⌘K→落笔→徽章→还白→重开，全链一口气 | 任一环断 → 必红 |
