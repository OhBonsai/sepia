## 一 · 分镜逐条

### 镜 0 · 冷启动（⭐ Aha #1）

- [ ] 双击（或 `bun dev` 启动）→ **昨晚那张纸已经在屏上**，不是空白、不是"最近文件"列表
- [ ] **光标停在上次的位置**，滚动位置也是上次那里
- [ ] 全程**没有任何弹窗**（不许有"正在加载""欢迎"之类）
- [ ] 体感 **1 秒之内可以开始打字**（机器实测 t0→t5 559ms，这里只判体感）
- [ ] ⏭ 角落 Agent 状态小点（灰→实心）——**缺口 #3，Stage 8**

### 镜 1 · 写字与 live preview

- [ ] 接着写一段，`## 小标题` 变大标题、`**关键**` 即时加粗
- [ ] **光标进入加粗词，只露那对 `**`**（元素级揭示 D-25），相邻的字不跟着动
- [ ] 用**拼音连续输入**一段（≥50 字）：候选框不闪、不吃字、无重排抖动
- [ ] 长文（拿 `art/` 里最长的一篇）滚到底再滚回顶，无卡顿
- [ ] ⏭ ⌘B / ⌘I / ⌘1~6 等标准快捷键——**缺口 #1，Stage 8**

### 镜 2 · 图片

- [ ] **⌘V 粘一张截图**进正文 → 落盘 + 正文出现 `![](img/…)`
- [ ] **从 Finder 拖一张图**进来 → 同样落盘（机器只覆盖了合成事件，真实拖拽只有人能验）
- [ ] 图**自成一行**，没有挤进上一行的标题或段落里（6b 修过的那处）
- [ ] 光标移开后**看得见图本身**，不是一行源码
- [ ] 落点是 `book/img/<时间戳>-<原名>`，重名不覆盖

### 镜 3 · `/` 菜单与 textdiagram

- [ ] ⏭ 敲 `/` 出菜单——**缺口 #2，Stage 8**
- [ ] 手写一个 ```textdiagram 围栏块，点到别处 → **失焦渲染**；点回去 → 变回源码
- [ ] ⏭ mermaid 真渲染（现在是 pre 盒）——**缺口 #2，Stage 8**

### 镜 5–7 · ⌘K markup（⭐ Aha #2 前半）

> **这几镜要用真 key、真模型**（`test/manual/a4-real-engine.spec.ts` 那套凭据）。
> mock 覆盖不到的正是这里：动词合不合用、话说得像不像人、快不快。

- [ ] 选中一段 → **⌘K** → 浮层**原地展开**（不是侧栏、不是弹窗）
- [ ] 浮层 = **一行输入 + 一列动词**，没有别的家具（D-29 第一层）
- [ ] 打字时动词列**隐去**
- [ ] 提交后**立刻**换成"生成中"，不等首 token
- [ ] 首 token **3 秒内**到（体感）
- [ ] 出结果是 **diff**：原文划线、新文对照，**正文一个字没动**
- [ ] 追问一句（如"那句自嘲要留下"）→ 同一个 thread 续聊，diff 更新
- [ ] Esc 中断：**中断之后正文仍然一个字没动**
- [ ] ⏭ 浮层里切模型 → 重试——**查证结果：没有实现**。`重试` 按钮有，
      但 D-29 说的「模型切换收进重试下拉」那半没做；桥上 `listModels` 一直在，
      **浮层里没有任何人调用它**。这是 185 四个缺口之外的**第五个**，
      Stage 7 收尾时查出来的，已记入 185 与 190

### 镜 8 · 落笔（⭐ Aha #2 完成）

- [ ] 点「落笔」→ 正文替换、浮层收起
- [ ] **段落边缘浮现一枚徽章**，克制（直径 8px 的小点，没有数字没有头像）
- [ ] 落笔**只改选中那段**，前后段落逐字节没变（打开 git diff 看一眼最直观）
- [ ] 体感 **300ms 内**完成

### 镜 9 · `@` 引用

- [ ] 敲 `@` → 列表**贴着光标**出现（不是钉在窗口某处）
- [ ] **即时**（<100ms 体感）；打字过滤跟得上
- [ ] 选中 → 插入的是**标准 md 链接**，在别的编辑器里打开也是同一个意思
- [ ] 点这个链接能打开那篇
- [ ] ⏭ "这次 markup 的对话可带该文做 context"——**缺口 #4，Stage 8**

### 镜 10 · 还白

- [ ] **⌘⇧H** → 全部徽章消失，纯纸
- [ ] 再按一次 → **一条不少**地回来

### 镜 11 · 关闭

- [ ] 直接 **⌘Q** → **没有保存对话框**，就是关掉了
- [ ] 关之前故意留几个没保存的字，⌘Q 之后重开 → 字还在（自动写盘兜住了）

### 镜 12–13 · 次日重开与线程面板

- [ ] 重开 → 昨天的纸、tab、光标、**徽章**都在（徽章这条是 Stage 7 修的那处）
- [ ] **点徽章** → 线程面板直接展开这一条（不是给一张列表让你找）
- [ ] 面板里看得到**完整对话过程 + 那段的 diff**
- [ ] 把已落笔的那段手动改几个字 → 徽章变**孤儿**，且孤儿有地方可见（不是凭空消失）

### 镜 14 · 出稿

- [ ] 用外部工具（`publish-prep.sh` / 别的编辑器）打开这篇 → **就是一份普通 markdown**，
      没有任何 Sepia 私有标记
- [ ] `git log` 看得到成对 commit；`.sepia/` 里的东西不影响这份 md

### 支线 X · Agent 缺席（W12）

- [ ] 把引擎弄坏（改配置/断网/删 key）→ 顶部**一条细线**提示，不是弹窗
- [ ] **纸照常可写**：写作、组件、图片、git、已有徽章回看**全部可用**
- [ ] ⌘K 唤起时**说明原因**，而不是无反应

## 二 · Stage 7 三块新家具

### ⌘/ 快捷键看板（D-32）

- [ ] ⌘/ 唤起，**一屏放得下、不出滚动条**
- [ ] 按 ⌘/ **不会在正文里留下任何东西**（这一条实测栽过：CM6 默认把 ⌘/ 绑成注释）
- [ ] 五组分类看着合理，键帽读得清
- [ ] 搜「加粗」或「B」都能命中；**没命中的只是隐去，命中的位置不动**
- [ ] 此刻按不了的是灰的（如没开 page 时的"保存"）
- [ ] 里面**回车不会执行任何东西**——它是看板不是命令面板
- [ ] Esc 或再按 ⌘/ 关掉
- [ ] **一眼能找到你想要的那个键**（这条只有人能判）

### ⌘⇧I 信息浮层（D-30）

- [ ] ⌘⇧I 出浮层，右下角，半透明卡片感
- [ ] 七行都读得懂：字数 / 上次保存 / 最近 commit / 线程 / book / 路径 / Agent
- [ ] **一屏读得懂**，不需要琢磨（这条只有人能判）
- [ ] 再按一次或**随便打个字**就淡出
- [ ] 里面**没有任何按钮**（它是一瞥，不是干活的地方）

### 保存微反馈与失败终态链

- [ ] 保存成功 → 纸角**极轻一闪**就没了，无 toast 无声音
- [ ] 这一闪**不打扰写字**（连着存几次也不烦）
- [ ] 把 book 目录 `chmod 555` → 打字 → **警示点出现**且**留着不走**
- [ ] 大约 13 秒后（1+3+9s 三次重试）横条说"存不进磁盘"
- [ ] 此时**关窗 → 被拦住**，提示里说得清有多少字没落盘
- [ ] 点「取消」→ 回到写作，字还在
- [ ] `chmod 755` 恢复 → ⌘S → 警示点消失；**再关窗不再拦**（"恢复即消"）
- [ ] **反过来的那一半更重要**：一切正常时关窗/⌘Q **一个对话框都不许出现**
