## 一、主页（Home）

进入方式：Tab 栏最左 ⌂ 按钮；应用启动时若无上次文件也落在这里。

### Layout

```
┌──────────────────────────────────────────────────────┐
│ Tab 栏（⌂ 高亮）                                       │
├───────────────┬──────────────────────────────────────┤
│ 左栏 · 220px  │  主区                                 │
│               │                                       │
│ Notes      ＋ │  ┌────────────────────────────────┐   │
│ ┌───────────┐ │  │ ⌕ 在 sepia 中搜索笔记           │   │
│ │ S  sepia  │◀│  └────────────────────────────────┘   │
│ └───────────┘ │                                       │
│  V vault-…    │  最近的笔记            ✎ 新建笔记      │
│  S shader-lab │  ───────────────────────────────────  │
│  读 读书笔记   │  S 2608-sdf-平滑合并.md    12 分钟前   │
│  I inbox      │  S 2607-raymarching…       昨天       │
│               │  S 2605-距离场与法线…       3 天前     │
│ ─────────────  │  S 2604-着色器热重载.md     上周      │
│ ◎ 设置        │  S 2512-mermaid-在笔记里   2025-12-04 │
│ ? 帮助        │  S 2411-为什么不用大纲…    2024-11-19 │
└───────────────┴──────────────────────────────────────┘
```

三个区：**左栏上半** = workspace 列表；**左栏下半** = 设置/帮助；**主区** = 搜索 + 最近笔记流。

### 功能

| # | 功能 | 行为 |
|---|---|---|
| H1 | **Workspace 列表与切换** | 多 book 并存（sepia / vault-template / shader-lab / 读书笔记 / inbox），每库一个字母头像方块，当前库高亮；点击切换整个上下文（笔记流、搜索范围、Agent cwd 随之切换）⚠️ 见第六节 |
| H2 | **新建 Workspace** | 左栏标题行 `＋`；新建 = 选一个本地文件夹作为 book |
| H3 | **book 内搜索** | 主区顶部搜索框，占位文案带当前 book 名（「在 sepia 中搜索笔记」），范围 = 当前 workspace ⚠️ 见第六节 |
| H4 | **最近的笔记** | 按相对时间分组：12 分钟前 → 昨天 → 3 天前 → 上周 → 绝对日期（越久越粗粒度）；每行左侧是所属 book 的字母角标；点击进 Page 页 |
| H5 | **新建笔记** | 「最近的笔记」标题行右侧 `✎ 新建笔记`，新建后直接进 Page 页并聚焦光标 |
| H6 | **设置入口** | 左栏底部 ◎，打开设置浮层（界面三）；等价快捷键 **⌘,**（任意界面可用，不限主页） |
| H7 | **帮助入口** | 左栏底部 ?（原型中为占位，见第七节） |

## 二、Page 页（纸）

Sepia 的主界面，绝大多数时间停在这里。

### Layout

```
┌────────────────────────────────────────────────────────────────┐
│ ⌂ │ 2608-sdf-平滑合并.md ■ × │ 2607-raymarching… │ 2605-… │ + │ ▤ │
│   └ 当前 tab（■未保存 ×关闭）   其他 tab             新建  MCP/SKILL│
├─────────────────────────────────────┬──────────────────────────┤
│  纸 · 单栏限宽居中                    │  右侧区（可关）            │
│  ┌───────────────────────────────┐  │  ┌──────────────────┐    │
│  │ 文件名           ▤  🔗  💬 ←──┼──┼──┤ 三个图标的去处：   │    │
│  │ ─────────────────────────────  │  │  │ ▤属性=行内展开    │    │
│  │ [属性表 title/date/tags/status]│  │  │ 🔗连接=右侧面板   │    │
│  │                               │  │  │ 💬对话=右侧面板   │    │
│  │ 正文（living 编辑）           ● ←──┼─ 段落右缘徽章       │    │
│  │ [组件块：图 / 图表 / shader]   │  │  └──────────────────┘    │
│  └───────────────────────────────┘  │                          │
│        ⌘+点击 @引用 → 右侧区变成第二个编辑器（中缝可拖宽）        │
├─────────────────────────────────────┴──────────────────────────┤
│ （无常驻底栏 · ⌘⇧I 唤出信息浮层于右下角，保存时该处一闪）          │
└────────────────────────────────────────────────────────────────┘
```

要点：右侧那一栏是**复用**的——可能是面板（连接 / 对话），也可能是第二个编辑器（@ 双屏）。纸顶三个图标控制三样东西，但去处不同：**属性在纸里行内展开**，**连接和对话开右侧面板**。

### 功能 · 书写

| # | 功能 | 行为 |
|---|---|---|
| F1 | **Living 编辑** [D-25] | 元素级语法揭示：光标进入行内元素才显现那一对标记（~120ms 淡入），词本身保持排版；标题行仅露行首 `#`；选区跨元素时选区内标记全露；永远同一层文本，无「渲染/源码」双模式 |
| F2 | **标准快捷键集** [D-26] | ⌘B/⌘I/⌘E、⌘1~6/⌘0、⌘⌥C 代码块、⌘⌥Q 引用、⌘⌥U·⌘⌥O 列表、⌘⇧K 链接；Enter 续列表、空项退出、Tab/⇧Tab 缩进；全部 toggle 式（选中包裹/解包） |
| F3 | **自动保存与静默 commit** [D-19] | 停止输入 800ms 写盘；save / 定时 / markup 前后成对三触发 git commit，用户无感 |
| F4 | **`/` 组件菜单** | 空行触发，三项：textdiagram（mermaid）、shader（glsl 实时预览）、image；插入后即为标准代码围栏 / 标准图片引用 |
| F5 | **组件块 · textdiagram** | 编辑时是代码，失焦渲染成图；点击渲染态回到代码 |
| F6 | **组件块 · shader** [D-20/D-27] | 左代码右实时预览的分栏；预览区页脚「60 fps · 编辑即刷新」；中缝可拖拽调整预览宽度 |
| F7 | **图片** | ⌘V 粘贴 → 落盘 `assets/{时间戳}-{名}.png`（D-40 默认值，可配置） → 生成标准 `![]()`，纸上即时显示 |
| F8 | **Meta info（属性）** | 纸顶第一个图标切换 frontmatter 显隐：展开为 title / date / tags / status 的行内属性表（等宽键 + 值），收起则纸从正文开始；与设置「笔记属性：表格/源码/隐藏」联动 |

### 功能 · Agent

| # | 功能 | 行为 |
|---|---|---|
| F9 | **markup 对话** [D-29] | 选中 → ⌘K → 原地浮层（推开下文，非遮盖）。**按阶段发家具**：唤起 = 一行输入 + 一列随选中对象变化的动词（文字/代码块/图片/标题/引用各一组），打字即隐藏动词；生成中 = 流式状态 + 停止；出结果 = diff（原文划线/新文）+ 落笔/放弃/重试，模型切换收进「重试」下拉。空手 ⌘K 有空态提示 |
| F10 | **同线程追问** [D-12] | diff 下方追问输入框，同一 opencode session 再来一轮，diff 更新；可「重置到 diff」回上一版 |
| F11 | **徽章** | 落笔后段落右缘浮现 ≤8px 小点，悬停微放大；点开 = 该段完整对话过程 + before/after diff（diff 取自 git，非另存） |
| F12 | **一键还白** | ⌘⇧H 全局切换徽章显/隐；隐藏后纸上无任何 AI 痕迹 |
| F13 | **对话列表（右侧面板 · 对话）** | 本篇所有线程总账：每条显示指令摘要 + 锚点位置（末段 / 标题 / 第七段）；展开 = 完整对话 + diff；**底部置灰的孤儿线程**（原段落已删、锚点失效，对话与 diff 仍保留）[D-18] |

### 功能 · 组织与导航

| # | 功能 | 行为 |
|---|---|---|
| F14 | **多文件 Tab 栏** [D-28] | ⌂ 回主页 + 多个文件 tab（■ 未保存脏标、悬停 ×）+ `+` 新建。（tab 拖拽排序：原型未实现，待定） |
| F15 | **`@` 引用** | 行内触发即时搜索 book 内的 page（列表显示文件名），选中插入引用；文件里存的是标准 markdown 链接 |
| F16 | **@ 双屏**（⌘+点击） | 单击 = 当前 tab 跳转；**⌘+单击 = 右侧打开被引笔记**，是完整编辑器不是只读预览（右栏内可编辑、可 markup）；中缝可拖宽、两侧独立滚动、× 关回单纸；**永远只有两栏**，再 ⌘ 点新引用则替换右栏，不裂变多窗口。**双屏不改变 markup 上下文**（⌘K 只带选区前后文，右栏内容要用 `@content` 显式引入，D-31） |
| F17 | **连接面板（右侧面板 · 连接）** | 本篇引用关系一览：引了哪些 book 内的 page（每条带**位置标注**：末段 / 第九段 / shader 块 + 引用处原文摘录）、引了哪些外链（iquilezles.org、shadertoy，标「外链」）；点击跳转 |
| F18 | **外链内嵌浏览器**（原型中为占位框，交互未实现） | 正文里的 http 链接、以及连接面板里的外链条目，点击**在右侧区打开内嵌浏览器**，不跳出到系统浏览器——参照资料与写字同屏，理由同 F16。原型里右栏显示「内嵌浏览器占位 + 网址」，真实渲染与浏览器条（地址 / 前后退 / 刷新 / 在系统浏览器打开 / ×）待实现。**右侧区同一时刻只有一个占用者**（面板 / @双屏第二编辑器 / 内嵌浏览器三者互斥，后来者顶替） |

### 功能 · 状态

| # | 功能 | 行为 |
|---|---|---|
| F19 | **Agent 状态** [D-23] | 角落状态点：启动中（灰）→ 就绪（实心）；**缺席时**顶部一条细提示线（原型 UI 文案「Agent 缺席」），⌘K 按下给出原因，其余功能全部照常 |
| F20 | **MCP / SKILL 状态浮层** | Tab 栏最右图标（有更新时带角标）；浮层两个 tab：**MCP**（filesystem 已连接 / sqlite·notes.db 已连接 / shader-preview 未启动，带状态圆点）、**SKILL**（已装技能与启用状态）；点击进设置对应页 |
| F23 | **快捷键看板**（⌘/，未实现·设计定稿）[D-32] | 居中浮层，**一屏放下全部不滚动**（放不下=快捷键太多，该砍功能）；按五组分类三列瀑布排布（行内格式 / 块 / Agent / 文件与视图 / 行内触发），组标题沿用设置页三级分组下划线样式；每行 = 功能名 + **键帽**（1px 边框、等宽、组合键并排不加「+」；圆角属样式，待定）。三个细节：顶部搜索即过滤（打「加粗」或「B」都命中，只隐藏不重排）、**当前上下文可用的高亮不可用的置灰**（markup 浮层开着时 ⌘B 置灰、Esc/⌘K 高亮）、底部「在 设置 › 快捷键 里可以改键」可点跳转。只读，不是设置页那个可编辑列表。第二入口：⌘⇧I 信息浮层底部的「全部快捷键」 |
| F21 | **信息浮层**（⌘⇧I，未实现·设计定稿）[D-30] | **不做常驻底部状态栏**。⌘⇧I 在纸的右下角浮起一块半透明小卡片（非模态、不夺焦点、不推开正文），4~5 行灰字：字数（N 词 · N 字符）、上次保存时间、当前 commit 短 hash、Agent 状态、文件相对路径；再按 ⌘⇧I / Esc / 或一开始打字即自动淡出（~150ms）。快捷键提示不常驻，收进本浮层底部折叠入口或设置 > 快捷键页 |
| F22 | **保存微反馈 · 纸角一闪**（未实现·设计定稿）[D-30] | 写盘完成那一刻（防抖 800ms 后），纸的右下角一个极轻的高光淡入淡出（~600ms）后彻底消失——幅度小到「只在你恰好看那儿时才看见」，不移动布局、无 toast、无「已保存」字样。**平时无声，出事才留痕**：写盘或 git commit 失败时，同一位置变成**持久的警示点**，点开看原因。这个角落平时是呼吸，异常时才是路标 |
