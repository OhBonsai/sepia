## Aha Moment（双 Aha，保护顺序 #1 > #2）

**Aha #1 · 白纸秒开（底线型）**：双击图标 → 光标可写，**< 1 秒**。它每天发生，是 Sepia 和"又一个 Electron 巨兽"的分界线。所有启动路径上的东西（sidecar、文件树索引、trace 加载）都必须让位：异步、懒加载、不挡光标。

**Aha #2 · 首次 markup 落笔（灵魂型）**：选中 → ⌘K → 讨价还价 → diff → 落笔 → 徽章浮现（分镜 5-8）。这是 Sepia 区别于所有编辑器的那一下。必须保护：选中到看到完整 diff **< 15 秒**，落笔瞬间完成。

（shader 块已移出 MVP（D-27），v2 回归时也不承担 Aha 责任。）

## Aha #1 的工程指标分解

| 段 | 预算 | 控制策略 |
|---|---|---|
| 进程启动 → 窗口可见 | < 500ms | Electron 窗口先行，一切初始化后置 |
| 窗口 → 上次的纸渲染 + 光标就位 | < 500ms | 只读一个文件；文件树/trace/git 状态全部异步 |
| sidecar spawn + 健康检查 | ≤ 5s，后台 | 不阻塞任何 UI；就绪前 ⌘K 显示"启动中" |

## Aha #2 的工程指标分解

| 段 | 预算 | 控制策略 |
|---|---|---|
| ⌘K → 浮层就位 | < 50ms | 纯前端 |
| 提交 → 首 token | < 3s | 闭手模式（工具全关）+ 上下文只带选区±前后文与 @content，session 预热（sidecar 就绪时预建） |
| 首 token → 完整 diff | < 12s | system prompt 锁定"只返回改写文本"，无工具往返 |
| 落笔（替换 + 成对 commit + 徽章） | < 300ms | git 操作异步，UI 先行 |
