### 执行模式（人裁 2026-08-04：顺序确定，尽量一次做完）

**一个连续 goal 跑完全程，不按类分批交付**。真人验证集中在收尾一轮（§1.6b），
避免 Stage 1 那种逐条来回。唯一的例外是一个**异步**早期 gate：

- CC 先做**行内公式**（顺序第 1 位）并出证据包 → 通知人抽 5 分钟做真 IME 验证；
- **CC 不等结果**，继续按顺序铺 A 类 → C 类 → B 类 → 剪贴板/查找替换/撤销；
- 若真 IME 验证失败，受波及的只有 replace decoration 一族（A 类行内），
  行装饰（B）与块 widget（C）不受影响——顺序设计保证了返工面最小。

实施顺序（风险最大的最先撞，降级预案齐的最后做）：
**① 行内公式（IME 考验场，异步人工 gate）→ ② A 类配置表铺开 → ③ C 类 widget 机制一次建四用
→ ④ D 类 + 代码高亮 → ⑤ B 类（最重，降级预案已写死）→ ⑥ 剪贴板 → ⑦ 查找替换 → ⑧ 撤销核验**

### 明确不做什么

**属于后面 stage 的**（一件都不碰）：
- **L2 widget 编辑**（点单元格加行加列、可视化编辑公式）——依痛感排后续（架构 §4.4b）
- **流式揭示动画**（24ms 批次、词边界 snap、四条稳定性不变量）——那是 markup 流式渲染，Stage 4
- **Shiki 与 `check:theme`**——随流式 markdown 库，Stage 4（前置四已裁）
- **阅读模式**——外链仍只做系统浏览器打开（Stage 7）
- **watcher / 自动保存 / git**——Stage 5/6，与 120 同一套刹车

**最容易顺手带出、必须刹住的**：

| 会顺手带出的东西 | 为什么手会滑 | 刹车 |
|---|---|---|
| **L2 单元格编辑** | 表格 widget 渲染出来了，点一下就想能编辑 | L1 为止。光标进入=变回源码，就是全部交互 |
| **语言高亮包铺满** | `language-data` 在手边，加一行支持一门语言 | 惰性加载 + §1.3 清单为准；清单外的语言按无高亮纯文本呈现，不算缺陷 |
| **shadcn 组件铺开** | 装都装了，别的 UI 也想换成它 | 只装查找替换所需；组件清单在 §1.3，超出走回填 |
| **主题切换 UI / 自定义主题** | 色板扩容了就想给个界面 | 架构 §1.3 非目标。改配置就是改文件 |
| **book 级全文搜索** | ⌘F 做完就想全局搜 | 非目标。篇内为止 |
| **揭示动画/过渡** | 光标进出揭示做完就想加缓动 | opencode 气质规则：即时切换。动效全归 Stage 4 流式 |
| **多 Tab** | 长文来回跳想开两个 | 仍是 Stage 6。`session.json` 不建 tab 字段 |
| **导出/发布** | 剪贴板 HTML 都有了，导出仿佛只差一步 | 发布场景经剪贴板粘贴，导出文件不在 MVP |

| 包 | 本 stage 新增 | 深度 |

| `core` | 类型与 copy 扩容 | — |

**风格裁决（人裁 2026-08-04：引入 shadcn，风格参考业界/opencode）**，具体方案：

- **结构用 shadcn**，但只装本 stage 用到的组件（查找替换：input/button/popover 一类），
  不整库铺开——组件清单预先声明，进 §1.3 依赖表。
- **色板用 Flexoki 映射进 `--sepia-*` 变量表**（人裁 2026-08-04：按此推荐）：Flexoki 是
  Obsidian CEO Steph Ango 做的「纸墨」配色（paper `#FFFCF0` / ink `#100F0F`，亮暗双版，
  **自带完整语法高亮色板**，MIT）——与 Sepia 的纸/墨隐喻同源，现有变量本来就叫
  `--sepia-paper` / `--sepia-ink`，是自然补全；语法高亮色板正好喂给本 stage 的
  D 类/代码高亮，也是 Stage 4 `check:theme` 的同源真相。
- **气质规则借 opencode**：无阴影（层次靠边框与底色）、4px 圆角、无渐变无模糊、即时状态切换。
  opencode 的 Berkeley Mono 是付费字体，不引；编辑器字体栈维持 ui-monospace。
- **主题变量表仍是唯一真相**：shadcn 的 CSS 变量必须映射到 `--sepia-*`，
  组件不得出现字面色值（纪律 3 不因引库放松）。

依赖边不变。`editor ↮ ui` 在语法色板上第二次受考验：色板变量名共享、代码不共享。

**新增第三方依赖（预先声明，003 §1.3）**：`@codemirror/lang-markdown` + `@codemirror/language-data`
（惰性加载，D 类/代码高亮用）、KaTeX（块级+行内公式渲染）、shadcn 所需的
radix-ui 原语（仅查找替换用到的）、【表格/textdiagram 渲染器：实施前补】。
实施时若与此清单不符，以 diff 为准并回填。
